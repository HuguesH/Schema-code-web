# struC4UML pour VS Code Web

Créez et explorez des diagrammes PlantUML et des modèles Structurizr DSL directement dans VS Code Web.

## Diagrammes PlantUML

- Coloration syntaxique et complétion pour les fichiers `.puml`, `.plantuml`, `.pu` et `.iuml`.
- Prévisualisation avec le bouton œil dans l’éditeur ou avec **PlantUML: Prévisualiser le diagramme** depuis le menu contextuel d’un fichier.
- Aperçu actualisé à mesure que le document est modifié, avec zoom, réinitialisation du zoom et export SVG.
- Prise en charge des directives `!include`, `!include_once` et `!include_many`, ainsi que des bibliothèques standards PlantUML.
- Affichage des sprites SVG d’un diagramme avec la commande `listsprites`.

Le rendu est effectué localement dans le navigateur : aucun serveur Java ou service PlantUML en ligne n’est nécessaire.

## Structurizr DSL

Les fichiers `.dsl` et `.structurizr` bénéficient de la coloration syntaxique, de complétions et de diagnostics pour repérer les erreurs structurelles courantes.
