# PlantUML standard-library bundles

These browser bundles are copied without modification from the official
PlantUML JavaScript distribution at
<https://plantuml.github.io/plantuml/js-plantuml/>. They are loaded from the
extension's local webview resources; no standard-library code is fetched at
runtime. The upstream source and license metadata below is supplied by each
bundle or its standard-library README. License texts available from the source
projects are included in `licenses/`.
